What does CHAR(2) + INTEGER EXTERNAL(4) mean?

Two text bytes followed by four bytes of decimal text, such as AB0042. The six-byte practice case shows this layout. Oracle’s INTEGER(4) means a binary integer; it is a different format, included as an unsupported example.
